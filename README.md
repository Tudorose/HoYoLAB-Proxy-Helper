# HoYoLAB-Proxy-Helper
HoYoLAB APl connectivity helper for Snap Hutao. Provides connection diagnostics and domain-redirection status via your proxy server

基于胡桃工具箱开发的胡桃工具箱插件，使用自建反向代理帮助HoYoLAB用户连接胡桃工具箱。

# 您需要拥有一个域名，没有可以在cloudflare购买(一年仅需4至8美刀)。

在cloudflare免费注册一个账号，如果你不知道如何设置的话你可以连接到你的智能体，在智能体中完成dns转发配置。

安装插件后，在插件设置中填写你的代理服务器域名，保存设置，完全重启胡桃工具箱后即可正常使用。
